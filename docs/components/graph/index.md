# GGraph

A force-directed graph rendered as SVG. Nodes can be dragged with the mouse or moved with the arrow keys (hold Shift for single-pixel steps), and both nodes and edges have delete buttons that can also be triggered from the keyboard. Edges reference nodes by id. Graph state is two-way bound via `v-model`.
